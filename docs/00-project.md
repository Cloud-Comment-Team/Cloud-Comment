# Паспорт проекта Cloud-Comment

Состояние на 24.11.2026. Репозиторий: https://github.com/Cloud-Comment-Team/Cloud-Comment.

## Назначение и границы

Cloud-Comment — существующий проект команды: сервис подключаемых комментариев для сайтов. Он позволяет владельцу добавить обсуждения без разработки собственного сервера комментариев и управлять публикациями. Признаков форка в локальном репозитории не обнаружено; происхождение и состав учебной команды необходимо подтвердить у владельца.

Пользователи: **владелец сайта** подключает и настраивает виджет, просматривает и модерирует комментарии; **посетитель** читает обсуждения и оставляет сообщения. Основные сущности: пользователь, сайт, обсуждение страницы, комментарий, действие модерации. Три основные функции: подключение виджета к сайту, публикация и чтение комментариев, модерация комментариев владельцем.

Стек: Java 25, Spring Boot 4.1.0, Gradle 9.6.0, PostgreSQL 18, React 19, TypeScript, Vite, Node.js 24, Caddy и Docker Compose. Исходные зависимости интерфейсов закреплены в `package-lock.json`; версии backend управляются Spring Boot и Gradle, но отдельного Gradle lock-файла нет. Docker-образы используют изменяемые теги основных версий.

**Лицензия:** файл LICENSE отсутствует; правообладателю необходимо выбрать и утвердить лицензию. До этого нельзя считать проект открыто лицензированным. **Команда и роли:** в истории есть несколько авторов, но состав команды для этой лабораторной и распределение обязанностей не подтверждены. Ответственных за требования, разработку и тестирование нужно указать после согласования; оценки ниже рассчитаны на одного исполнителя.

## Структура проекта

| Каталог | Назначение |
| --- | --- |
| `backend/src/main/java/com/cloudcomment` | Spring Boot API; пакеты `auth`, `site`, `comment`, `moderation`, `discussion`, `analytics`, `notification`, `realtime` и другие организованы по предметным областям; внутри — API, application, domain и persistence. |
| `backend/src/main/resources` | Профили Spring и миграции Flyway. |
| `backend/src/test` | Модульные, HTTP и интеграционные тесты, в том числе с Testcontainers. |
| `frontend/admin/src` | React-приложение владельца: страницы, API-клиенты, компоненты и состояние. Точка входа — `main.tsx`. |
| `widget-frontend/src/widget` | Встраиваемый loader, изолированный iframe, отображение и API виджета; точки входа — `index.ts` и `frame.ts`. |
| `docker/`, `docker-compose.yml` | Сборка контейнеров, Caddy и локальная инфраструктура. |
| `deploy/` | Конфигурация и сценарии развёртывания. |
| `.github/` | CI/CD, шаблоны и вспомогательные проверки. |
| `docs/` | Документация и исходник C4-диаграммы. |

Точка входа сервера — `backend/src/main/java/com/cloudcomment/CloudCommentApplication.java`. Данные хранятся в PostgreSQL; схема версионируется Flyway, локальный том Compose сохраняет её между запусками. Caddy раздаёт интерфейсы и проксирует API; для уведомлений используется WebSocket, для почты предусмотрен SMTP либо локальное логирование. Настройки задаются через `.env`, переменные окружения и `application*.yml`; примеры находятся в `.env.example` и `.env.production.example`. Секреты не следует добавлять в репозиторий.

## Карта функций

| Функция | Реализация | Ручная проверка после запуска |
| --- | --- | --- |
| Регистрация и вход владельца | `backend/.../auth/api/AuthController.java`, `frontend/admin/src/pages` | Открыть главную страницу, зарегистрироваться или войти. |
| Добавление сайта | `backend/.../site/api/SiteController.java`, `frontend/admin/src/pages/Sites` | Войти и добавить сайт. |
| Получение кода виджета | `backend/.../site/application/EmbedCodeService.java` | Открыть настройки сайта и скопировать код подключения. |
| Просмотр комментариев | `backend/.../comment/api/PublicCommentController.java`, `widget-frontend/src/widget/render.ts` | Открыть `/demo-page.html` и увидеть обсуждение. |
| Публикация комментария | `backend/.../comment/application/PublicCommentService.java`, `widget-frontend/src/widget/frame.ts` | На демостранице отправить комментарий и убедиться в его появлении с учётом модерации. |
| Ответ владельца | `backend/.../discussion/api/DiscussionController.java` | Открыть обсуждение в панели и ответить. |
| Модерация | `backend/.../moderation/api/ModerationController.java`, `frontend/admin/src/pages/Comments` | В панели изменить статус комментария и проверить результат. |
| Настройка внешнего вида | `backend/.../site/domain/WidgetStyle.java`, `frontend/admin/src/utils/widgetStyle.ts` | Изменить стиль сайта и проверить виджет. |
| Аналитика | `backend/.../analytics/api/OwnerAnalyticsController.java`, `frontend/admin/src/pages/Analytics` | Открыть аналитику сайта после появления активности. |

В таблице `backend/...` означает `backend/src/main/java/com/cloudcomment`. Сценарии требуют работающего окружения и не заявляются проверенными в рамках этого документа.

## Первые наблюдения

1. Нет лицензии: условия распространения и изменения не определены (question).
2. Gradle не имеет lock-файла, а базовые образы используют изменяемые теги; повторная сборка может получить другие зависимости (question).
3. Нет подтверждённого протокола запуска на чистой машине; Docker daemon на текущем рабочем месте недоступен (bug/question: требуется воспроизвести и проверить окружение).

Тексты для создания issues и согласования приведены в `docs/lab-1-issues.md`. До создания на GitHub они не считаются issues.

## Выполнимость и план

| Риск | Вероятность | Последствия | Снижение |
| --- | --- | --- | --- |
| Большой существующий код и несколько технологий | Высокая | Не хватит времени изучить весь проект | Ограничить семестр основными сценариями, изучать по карте функций. |
| Docker, загрузка образов и интеграционные тесты | Средняя | Невозможность воспроизвести запуск | Подготовить чистую машину с Docker, заранее проверить сеть и кэш. |
| Недоступность участника или ограниченное время | Средняя | Срыв сроков | Выделить ответственных и резерв времени, отслеживать задачи. |
| Внешние SMTP, хостинг и доступы | Средняя | Невозможность проверить выпуск и почту | Локальное логирование почты и демонстрационный стенд; заранее согласовать доступы. |
| Лицензия не определена | Высокая | Неясны права распространения | Получить решение правообладателя до публикации условий. |

| Работа | План для Cloud-Comment | Оценка |

Предварительно в объём входят вход владельца, управление сайтом и кодом подключения, чтение и отправка комментариев, ответы и модерация. Расширенные политики автомодерации, аналитика, realtime и интеграция внешней почты остаются за рамками семестра, если преподаватель не согласует иное. План и оценки предварительные; распределение по участникам и одобрение преподавателя ещё не подтверждены.
